# LanMic 0.2.0 · 无密码直连

手机只需填写电脑的 IP 和端口，即可开始传音。

- 移除音频传输加密、证书指纹、密码和配对码。
- 两端界面同步精简，使用普通局域网 TCP 连接。
- 保留静音、电平、音量、音频输出选择、后台录音和有限断线重连。

**请同时更新 Windows 程序和安卓 APK。** 本版使用新的通信协议，不能与旧版 0.1.0 混用。

下载 `LanMic-Windows.zip`，解压运行；将 `LanMic-android.apk` 安装到手机。电脑先开始监听，手机填 IP 和端口后点击开始传输。

供微信、游戏或会议软件作为麦克风使用时，仍需 [VB-CABLE](https://vb-audio.com/Cable/)：LanMic 选 CABLE Input，目标软件麦克风选 CABLE Output。

此版本仍为开发预览；安卓真机录音、锁屏和实际延迟尚待实测。
